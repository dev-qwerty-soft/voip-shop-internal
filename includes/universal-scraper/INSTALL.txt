# 🚀 ІНСТРУКЦІЯ - Як перенести парсер в іншу тему

## ✅ ВСІ ФАЙЛИ В ОДНІЙ ПАПЦІ: `includes/voipx3-parser/`

```
voipx3-parser/
├── product-scraper.php    ← Парсинг товарів і категорій
├── product-importer.php   ← Імпорт в WooCommerce
├── admin-page.php         ← Адмін панель
├── admin.js               ← JavaScript
├── admin.css              ← Стилі
├── init.php               ← Ініціалізація (головний файл)
└── README.md              ← Документація
```

---

## 📋 КРОК 1: Копіювання файлів

### Варіант A: Ручне копіювання
1. Скопіюйте папку `voipx3-parser`
2. Вставте в `wp-content/themes/ВАША-НОВА-ТЕМА/includes/`

### Варіант B: Через FTP/FileZilla
1. Завантажте папку `voipx3-parser` на сервер
2. Розмістіть в `/wp-content/themes/ВАША-ТЕМА/includes/`

---

## 📝 КРОК 2: Підключення в новій темі

Відкрийте `functions.php` вашої **НОВОЇ ТЕМИ** і додайте в кінець файлу:

```php
// ============================================
// VOIPx3 Product Parser - Парсер товарів
// ============================================
require_once get_template_directory() . '/includes/voipx3-parser/init.php';
```

**ВАЖЛИВО:** Якщо папка `includes` не існує, створіть її!

---

## ✅ КРОК 3: Перевірка

1. Оновіть сторінку WordPress Admin
2. В лівому меню з'явиться пункт **"Product Import"** (з іконкою завантаження)
3. Клікніть на нього - має відкритися сторінка парсера
4. Готово! 🎉

---

## 🔧 Налаштування (опціонально)

### Змінити URL сайту для парсингу

Відкрийте `voipx3-parser/product-scraper.php`, знайдіть:

```php
private $base_url = 'https://voipx3.com';
```

Змініть на ваш URL.

### Додати нові категорії

У файлі `product-scraper.php` знайдіть метод `scrape_products_by_categories()` і масив `$category_keywords` - додайте свої ключові слова.

---

## 🐛 Що робити якщо не працює?

### Проблема 1: Меню не з'являється
- Перевірте що шлях до `init.php` правильний
- Перевірте що папка `includes` існує
- Очистіть кеш WordPress (якщо використовуєте кеш-плагіни)

### Проблема 2: Парсинг не працює  
- Перевірте що **WooCommerce активований**
- Перевірте що сервер може робити зовнішні HTTP запити
- Натисніть кнопку "Debug HTML" для перевірки з'єднання

### Проблема 3: Помилка "Class not found"
- Перевірте що ВСІ 5 PHP файлів скопійовані
- Перевірте права доступу на файли (644 для файлів, 755 для папок)
